name: course-report
description: 根据课程要求生成可保存的结构化 Markdown 课程报告草稿。
version: 1.1.0
---
用于课程小论文、课程学习总结和课程实验报告。

先收集或确认：课程要求、报告类型、题目或主题、目标读者、字数、截止要求、参考材料，以及可选的工作区保存路径。信息不足时，只追问会影响报告结构或事实准确性的内容。

输出时给出完整、结构化的 Markdown 草稿，而非只给提纲。草稿应包含合适的标题、摘要、正文分节和参考资料说明；实验报告还应包含实验目的、方法、结果与分析。严格遵守用户给出的字数和结构要求；事实、数据和引用只可来自已提供材料，其他内容须标为“待核验”。

用户未提供保存路径时，在对话中返回 Markdown 草稿。用户提供相对工作区的保存路径且工作区已配置时，使用 `write_file` 将草稿写入该路径；这是工作区写入操作，必须等待现有审批流程通过。审批被拒绝、工作区未配置或写入失败时，不得改用 Shell 写入；保留并返回草稿，并简要说明未保存原因。
