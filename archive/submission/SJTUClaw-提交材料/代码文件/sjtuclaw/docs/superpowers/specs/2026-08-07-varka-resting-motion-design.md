# 法尔伽桌宠静止待机设计

## 目标

消除桌宠在无须表达工作进度时持续循环动画造成的“抽搐”观感。桌宠平常保持静止，仅在启动欢迎、任务执行和用户拖动时播放动画。

## 范围

- `idle`、`waiting`、`review`、`failed` 固定显示各自动画行的第 0 帧，不再设置循环计时器。
- `waving` 仍在首次显示时完整播放一次；完成后保持当前业务状态的静止帧。
- `running`、`running-left`、`running-right` 保持既有循环动画，用于表达任务执行和拖动方向。
- 保持精灵图行号、状态映射、提醒、Quick Chat、窗口交互和减弱动态偏好不变。

## 实现

在 `web/src/pet/state.ts` 将动画定义扩展为显式的循环/静止属性，令四个平常状态为非循环。`PetSprite` 仅为可循环状态建立帧推进计时器；静止状态始终渲染第 0 帧。减弱动态偏好继续强制第 0 帧。

## 验收

- 闲置、等待输入/审批、完成提醒、失败提醒期间，精灵图不再变帧。
- 启动欢迎只播放一次；执行中和拖动时仍播放现有动画。
- 现有状态映射和交互测试通过，Web 与桌宠构建通过。
